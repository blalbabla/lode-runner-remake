# Lode Runner 3D

A faithful remake of the classic Lode Runner in .NET 10 and Raylib-cs. It has all 150 original levels, a 3D presentation, a retro pixel font, procedurally synthesised sound, gamepad support, rebindable controls, and persistent high scores.

## Features

- All 150 original levels, unlocked progressively as you advance.
- Deterministic, integer-based simulation (`LodeRunner.Core`) with no graphics or audio dependencies.
- 3D rendering with dynamic lighting (falls back to unlit if shaders are unavailable), particles, and screen shake.
- Cinematic level intro: each new level fades in from black while the camera swoops from the hero's eyes back to the side view (any key skips it). Moving to the next level fades out and in.
- Death scenes: slow motion with a camera push-in and blood spray. A hero bricked into a hole convulses while the wall closes; a guard that catches him waves its arms; a guard falling on him flattens him; falling onto a guard sinks him into the monk.
- Keyboard and gamepad (up to 4 pads) with full rebinding.
- Top-10 high score table and lifetime stats.
- Enemy AI switch in Settings: Classic (original greedy guard rules, default) or Smart (shortest-path search).
- Game speed in Settings: Very slow / Slow / Normal (default) / Fast / Very fast. Scales the tick rate for player and guards alike.
- Graphics in Settings: High (default) has a shadow map from a sun at the viewer's shoulder, bump-mapped brick, brushed steel, metal ladders and glowing gold. Low keeps simple lighting for weak graphics cards.
- Fully procedural audio: no sound files. Footsteps, metal ladder rungs, stone menu slabs, bell pickups, vocal screams, a funeral toll, a choral win fanfare and a dark ambient drone are all synthesised in memory (see `docs/AUDIO.md`). Each effect has several pre-rendered variants so repeats never sound identical.
- Video modes, volume, and key bindings saved between runs.

## Controls

| Action      | Keyboard (default)      | Gamepad (default)      |
|-------------|-------------------------|------------------------|
| Move        | Arrows / WASD / Numpad  | D-pad / Left stick     |
| Dig left    | Z                       | X                      |
| Dig right   | X                       | B                      |
| Pause/menu  | Esc                     | Start                  |
| Confirm     | Enter / Space           | A                      |
| Back        | Esc                     | B                      |
| Restart lvl | R                       |                        |
| Next/prev   | N, PgDn / P, PgUp (unlocked levels only) | LB / RB (menus) |

In-game actions can be rebound from Settings > Controls. Menu navigation on a gamepad is fixed so you can never be locked out.

## Build and run

Requires the .NET 10 SDK.

```
dotnet run --project src/LodeRunner.Game -c Release
```

## Test

```
dotnet test --blame-hang-timeout 20s
```

## Publish

```
dotnet publish src/LodeRunner.Game/LodeRunner.Game.csproj -c Release -r win-x64 --self-contained false -o publish
```

The output contains `LodeRunner.exe` plus the `assets` folder (levels, fonts, icon). Keep them together.

## Data locations

Settings and high scores are stored under `%APPDATA%\LodeRunner\` (`scores.json` for scores).

## Layout

- `src/LodeRunner.Core` - simulation, levels, campaign, high score table.
- `src/LodeRunner.Game` - Raylib shell: rendering, audio, input, menus, settings.
- `tests/LodeRunner.Core.Tests` - unit tests.
- `docs/DESIGN.md` - design notes.
- `docs/AUDIO.md` - procedural audio engine.
